# FocusKid — Project Vision & Architectural Invariants

## 1. Mission & Core Problem

**Місія** — надати дитям (5–13 років) автономний інструмент формування корисних звичок, який перетворює рутину на прозорий, самостійний процес без суперечок, а батькам — гарантію чесності виконання завдань через фізичну верифікацію результату.

**Проблема**:
- **Мікроменеджмент**: Батьки змушені контролювати кожну хвилину, що створює конфлікти.
- **Нечесність таймерів**: Стандартні таймери дозволяють дитині «обдурити» систему (скинути, перемотати, вимкнути).
- **Хмарна залежність**: Існуючі трекери вимагають інтернет, акаунти, підписки, показують рекламу — це небезпечно для дитини і не працює в поїздках/режимі польоту.

**Рішення (Цикл «Фокус ➔ Результат ➔ Підтвердження»)**:
1. **Вибір**: Дитина сама обирає завдання з списку на сьогодні.
2. **Чесний таймер**: Запуск відліку без можливості примусового скорочення часу. Дозволена пауза (коротка) та довбування часу, але не «стоп» до закінчення.
3. **Реальний результат**: По завершенню таймер фіксує статус «Очікує перевірки». Дитина показує книгу/зошит/вправу батькам.
4. **PIN-підтвердження**: Батьки вводять 4-значний PIN у календарі — завдання стає «зеленим» (успішним).

**Ключова ідея — Двостороння довіра через архітектуру**:
- Дитина отримує автономію (ніхто не стоїть над душею).
- Батьки отримують криптографічно/фізично перевірений факт (PIN + очний результат).

## 2. Architectural Paradigms

- **Local-First / Zero-Network Architecture**: Жодних мережевих викликів. Всі дані (завдання, історія, PIN-хеші, налаштування) зберігаються локально на пристрої (SQLite / Room / DataStore). Працює в повітряному проміжку (Airplane mode).
- **Single-Device, Single-User (Multi-Profile) Model**: Один пристрій = один профіль дитини. Батьківський режим — це перемикання UI-стану за PIN, а не окремий акаунт.
- **State-Machine Driven Timer**: Таймер — це детермінований скінченний автомат (`Idle → Running → Paused → Completed → Verified`). Переходи строго валідовані; неможливо перейти `Running → Verified` минучи `Completed`.
- **Anti-Cheat Time Source**: Використання `SystemClock.elapsedRealtime()` (monotonic clock), який не змінюється при зміні системного часу користувачем. Заборона `setSystemTime` не впливає на відлік.
- **Reactive UI (Compose / Flow/LiveData)**: Екран таймера оновлюється в реальному часі (1 сек / 100 мс) без блокування головного потоку. Landscape-режим — окремий компоновний стан (DeskClock UI).
- **Secure Local Auth**: PIN батьків хешується (PBKDF2/Argon2) при створенні. Перевірка відбувається локально. Жодних «забув PIN» / reset через email — лише повне очищення даних додатку (Factory Reset).
- **Privacy by Design**: Zero PII. Жодних ім'я, дат народження, фото. Тільки абстрактні «Завдання» та «Дні».
- **Family Link / Parental Control Compatible**: `android:requiredAccountType` відсутній. Без `INTERNET` permission. Без `FOREGROUND_SERVICE` (крім можливості `mediaPlayback` для звуку завершення, опціонально). `android:allowBackup="false"` для ізоляції даних.

## 3. Hard Invariants (Технічні вето)

- [INV-01] **Zero Network**: Заборонено додавати `android.permission.INTERNET`. Будь-яка спроба додати мережну залежність (аналітика, краш-репорти, оновлення контенту) — блокується на етапі PR.
- [INV-02] **Monotonic Timer Integrity**: Відлік часу **виключно** через `SystemClock.elapsedRealtime()` або `System.nanoTime()`. Заборонено використовувати `System.currentTimeMillis()` для логіки таймера (користувач може змінити годинник).
- [INV-03] **No Early Termination by Child**: У стані `Running` дитина **не може** перевести таймер у `Completed` або `Verified` до сплину цільового часу. Дії: `Pause` (лімітована), `AddTime`. Кнопка `Stop/Finish` відсутня або неактивна до `onTimerFinish()`.
- [INV-04] **Pause Abuse Protection**: Пауза має ліміт (наприклад, макс. 5 хв за сесію або 1 хв безперервно). Перевищення → авто-резюме або блокування паузи до завершення поточного інтервалу. Логіка невидима для дитини (маскот «просить повернутися»).
- [INV-05] **Parent Gate via PIN Only**: Перехід у батьківський режим (редагування завдань, перегляд статистики, верифікація) можливий **тільки** через введення правильного PIN-хешу. Жодних «секретних жестів», довгих натискань, ADB-хаків.
- [INV-06] **Verification Immutability**: Статус `Verified` (зелений) є фінальним. Не можна скасувати верифікацію, змінити час назад, видалити запис з календаря (крім повного скидання даних додатку).
- [INV-07] **Data Persistence & Survival**: Дані (завдання, історія календаря, PIN-хеш) виживають: перезапуск додатку, перезавантаження ОС, оновлення версії додатку (через `Room` міграції), `adb backup` / `auto backup` (якщо увімкнено, але краще `allowBackup=false`).
- [INV-08] **Landscape Desk Clock Parity**: У Landscape-режимі таймер показує **те саме** час, той самий стан, той самий маскот. Не допускається розсинхронізація стану при ротації (ViewModel / `rememberSaveable` обов'язкові).
- [INV-09] **No Dark Patterns / Gamification Traps**: Заборонено: streak-штрафи (втрата прогресу за пропуск день), сповіщення-загадки, внутрішню валюту, лут-бокси, рекламу, пропозиції «купити більше часу». Маскот — емоційна підтримка, не маніпулятор.
- [INV-10] **Accessibility & Age Readability**: Мін. розмір шрифту таймера 48sp (портрет), 80sp (landscape). Контрастність WCAG AA. Підтримка TalkBack (опис стану: «Таймер біжить, залишилось 12 хвилин»). Кнопки ≥ 48x48dp.

## 4. Out of Scope (Non-Goals)

- **Хмарна синхронізація / Multi-device**: Не підтримуємо синхронізацію між телефоном та планшетом, бекап в Google Drive, спільний доступ батьків з власних телефонів.
- **Мультипрофільність (декілька дітей на одному пристрої)**: MVP — одна дитина = один пристрій. Розширення — окремий епік.
- **Віддалене керування батьків**: Батьки не можуть запускати/зупиняти таймер зі свого телефону, не отримують push-сповіщень «дитина закінчила».
- **Розумні нагадування / AI**: Не будуємо «розумний розклад», адаптивні таймери, прогнози.
- **Соціальні функції**: Лідерборди, друзі, спільні виклики, шаринг у соцмережі.
- **Гейміфікація за межами маскота**: Жодних XP, рівнів, аватарок, магазинів скінів, петель залучення (retention hooks).
- **Аналітика / Телеметрія / Краш-репортинг (Firebase, Sentry, Amplitude)**: Жодного трекінгу. Баг-репорти — лише через Google Play Console (анонімні) або відгуки користувачів.
- **iOS / Web / Desktop**: Тільки Android (API 24+ / Android 7.0+).
- **Розширена кастомізація маскота**: Один фіксований персонаж «Булька». Жодних виборів кольорів/одягу.
- **Експорт даних (CSV/PDF)**: Не в MVP. Історія тільки у візуальному календарі всередині додатку.

## 5. Target Constraints & SLOs

- **Target API Level**: `minSdk 24` (Android 7.0 — підтримка Family Link на старих пристроях), `targetSdk 34+`.
- **App Size (APK/AAB)**: ≤ **15 MB** (з ресурсами маскота, шрифтами, звуками). Без тяжелих бібліотек (без Room — можливо DataStore + простий SQLite wrapper; без Compose — можливо Views + Jetpack Compose для нових екранів, але вага важлива).
- **Cold Start Time**: ≤ **1.5 сек** до інтерактивного екрану «Сьогодні» (на пристрої 2018 р.в., Snapdragon 450 / 2GB RAM).
- **Idle RAM Footprint**: ≤ **50 MB** (фоновий сервіс відсутній, таймер працює у корутині ViewModel / Lifecycle Scope).
- **Battery Impact**: **Невимірюваний** у `Battery Historian` за 24 год бездіяльності. Таймер не тримає `WakeLock` (використовує `AlarmManager.setExactAndAllowWhileIdle` для сповіщення про кінець, якщо додаток згорнуто/екран вимкнено).
- **Timer Accuracy**: Похибка ≤ **±1 секунда** на 60 хвилин відліку (включаючи паузи, блокування екрану, Doze mode).
- **Offline Survival**: 100% функціональності без інтернету, без Google Play Services (пристрої з GMS Core відключеним / дешеві планшети для дітей).
- **Storage Growth**: ≤ **5 MB** за рік активного використання (текстові логи календаря).
- **Test Coverage Floor**: ≥ **80% branch coverage** для `TimerEngine`, `PinAuth`, `CalendarRepository`, `TaskScheduler`. UI-тести (Compose/Roboelectric) для критичних шляхів: запуск таймера → пауза → завершення → верифікація PIN → зелений день.
- **Accessibility Compliance**: Пройдення `Accessibility Scanner` без критичних помилок.
